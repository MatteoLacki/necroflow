necroflow feature tree
======================

necroflow
├── Core model
│   ├── Node typed file/artifact classes
│   ├── Node subtype families for format contracts
│   ├── Node union inputs for alternative type contracts
│   ├── fixed mixed Node/value unions with runtime parent selection
│   ├── Node typed output/edge/result selectors
│   ├── RuleCall atomic identity, cache, state, execution, report, cleanup
│   ├── Module-level rule declarations
│   │   ├── shell command factory: command(cmd, Inputs(...), Outputs(...), name=...)
│   │   ├── decorator sugar: @command(...)
│   │   ├── built-in decorators: @text_file / @symlink_file
│   │   ├── explicit built-in factories: text_file_rule / symlink_file_rule
│   │   ├── lint-clean name = output(Node) declarations
│   │   ├── typed Inputs / Outputs
│   │   ├── filename-less abstract input contracts; explicit output filenames
│   │   ├── scalar/config and mixed-value defaults with explicit Node dependencies
│   │   ├── ordered tuple[Node, ...] variadic inputs
│   │   ├── optional inclusive Many(min=..., max=...) bounds
│   │   ├── multi-output rules
│   │   ├── atomic co-output caching and execution per RuleCall
│   │   ├── Constraints: threads, ram, custom resources
│   │   ├── threads="all" reserves the full execution thread cap
│   │   ├── repeat=N permits up to N subprocess attempts, including the first
│   │   ├── built-in text_file rules for generated config files
│   │   └── built-in symlink_file rules for content-tracked external inputs
│   ├── Pipeline
│   │   ├── references a shared DAG and owns fingerprint/shell compile policy
│   │   ├── @workflow supplies scoped Pipeline ownership for rule(...) calls
│   │   ├── explicit rule(P, ...) supported anywhere; overrides the scoped owner
│   │   ├── nested workflows restore context; ordinary helpers inherit it
│   │   ├── explicit attribute/item node registration in one label namespace
│   │   ├── canonical relative POSIX path labels for nested visible results
│   │   ├── early label byte-limit and file/directory conflict rejection
│   │   ├── local aliases for manifests and requests
│   │   ├── prefixed shared-state views via P.subpipeline(...)
│   │   ├── root P.finish() freezes construction; CLI calls it after workflow return
│   │   └── conditional Python pipeline construction
│   └── DAG
│       ├── owns the node store and canonical RuleCall registry
│       ├── immediate shared-node interning across Pipelines
│       ├── requested target nodes
│       └── TGF graph rendering / save
│
├── Commands
│   ├── input/output path placeholders
│   ├── independently shell-quoted expansion of variadic input groups
│   ├── config placeholders
│   ├── {workdir} retained side-output directory
│   ├── constraint placeholders
│   │   ├── {threads}, default 1
│   │   ├── {ram} and other declared constraints
│   │   └── {constraint:name} forced constraint lookup
│   ├── escaped literal shell braces via {{...}}
│   ├── static shell templates
│   ├── Python callbacks receiving resolved CommandArgs
│   ├── configurable shellpath
│   └── Docker execution via leading {env}: prefix
│       ├── Docker(image@sha256, platform, run_args) config value
│       ├── overridable default run args; {uid}/{gid} expanded at launch
│       ├── read-only input binds at node paths, writable workdir
│       └── container_policy in provenance of container-capable rules
│
├── Caching and paths
│   ├── rebuilds cascade through active descendants by default
│   ├── --reuse-unchanged / reuse_unchanged=True opts into content-based reuse after rebuilds
│   ├── lineage-addressed node paths
│   ├── v4 recipe and provenance hashes compiled during rule calls
│   ├── full 64-character provenance path component
│   ├── filesystem cache as source of truth
│   ├── framework-owned recipe- and lineage-aware identity
│   ├── explicit shellpath included in command fingerprints
│   ├── path length validation
│   ├── destination-filesystem result-path preflight before copying
│   ├── output content hashes with mtime-gated stored-hash fast path
│   ├── consumed parent content-hash metadata (BLAKE3 default, SHA-256, or custom hasher)
│   ├── invalidator tokens on Node
│   └── .rip metadata directories
│
├── Execution engine
│   ├── parallel execution
│   ├── resource caps
│   │   ├── threads cap
│   │   ├── ram/custom resource caps
│   │   └── SI/binary resource parsing
│   ├── scheduler protocol
│   │   └── ready RuleCalls, remaining RuleCalls, available capped resources
│   ├── FIFO scheduler default using RuleCall insertion order
│   ├── custom schedulers
│   │   └── Python callables can implement resource-aware ordering policies
│   ├── per-run cache verdicts and runtime phases
│   ├── dry-run classification with parent-hash refresh
│   ├── keep-going failure mode
│   ├── fail-fast drains running calls and records them
│   ├── failed/interrupted state tracking, blocked descendants
│   ├── compromised-output reruns
│   ├── missing-output detection
│   ├── job logs
│   ├── execution reports
│   │   ├── .rip/run.toml RuleCall-local runtime stats
│   │   ├── results/<job>/execution.toml per-run summaries
│   │   ├── custom per-job summary callbacks via --reporter path.py:function
│   │   └── duration and output-size accounting
│   ├── output/provenance graph writing
│   ├── exclusive node-store lock through execution and CLI result publication
│   └── autoclean
│       ├── orphan cleanup
│       └── intermediate cleanup
│
├── CLI
│   ├── --scheduler selector
│   │   ├── fifo default
│   │   └── local Python callable
│   ├── legacy/default run form: necroflow job.toml
│   ├── explicit run subcommand
│   ├── init subcommand
│   │   └── canonical starter workflow scaffold
│   ├── graph subcommand
│   │   ├── --json machine-readable graph
│   │   └── --dot Graphviz DOT text (pipe to `dot -Tsvg`)

│   ├── provenance subcommand

Resource[int]: keyword scheduling quantities outside both hashes.
